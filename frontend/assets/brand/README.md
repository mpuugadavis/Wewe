# WEWE brand assets

WEWE connects campus people and shops. The joined W strokes suggest paths meeting; the repeated, custom-drawn WEWE letters give the brand a recognisable rhythm. All artwork consists of vector paths with no font dependency, embedded photos, gradients or filters.

## Choose the right file

- `wewe-logo-purple.svg`: primary horizontal logo on white or pale backgrounds.
- `wewe-logo-white.svg`: reversed horizontal logo on deep purple.
- `wewe-logo-ink.svg`: single-colour artwork for receipts, packaging and print.
- `wewe-symbol-purple.svg`, `wewe-symbol-white.svg`, `wewe-symbol-ink.svg`: compact mark for labels, apparel and small placements.
- `favicon.svg`: high-contrast white symbol in a purple tile, optimised for browser tabs.
- `preview.html`: brand sheet with sample apparel, packaging and website placements.

The primary colour is #6C3DF4 (RGB 108, 61, 244). Deep ink is #21113F. Paper is #F5F1FC. For commercial print, convert with the printer's ICC profile and approve a physical proof; RGB-to-CMYK values depend on stock and equipment.

## Sizing and production

Keep the viewBox and scale proportionally. Use at least 108 CSS pixels for the full logo, 24 pixels for the symbol; use the tile favicon at 16 pixels. Website header uses 142 pixels on desktop and 108–128 on mobile; footer uses 166; dashboard uses 140. Maintain clear space equal to one letter's stem thickness (about one eighth of the symbol width). Do not stretch, outline, rotate or add effects to the production logo.

For apparel/embroidery and single-ink packaging, use the symbol or monochrome logo. Recommended starting minimum print widths: full logo 35 mm, symbol 12 mm. Confirm stitch thickness and minimum gaps with the embroiderer before production. White artwork is intentionally transparent and needs a dark substrate. The assets remain editable in vector design tools and can be exported to EPS/PDF by a print supplier.

The active frontend uses this SVG family. Legacy raster branding and the old homepage backup are recoverable from Git history.
